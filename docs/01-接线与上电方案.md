# 硬件接口与配置

## 实际接线

开发板 40-pin 接口与 ZLink 控制板 UART 的接线如下，pin 为 40-pin 接口的物理针脚编号：

| 开发板针脚 | ZLink 控制板 UART |
|---:|---|
| 9 | GND |
| 8 | RX |
| 10 | TX |

ZLink 控制板由电池供电。

## 控制器与串口

项目使用 ZL-IS2 控制器。程序通过 Quectel Pi M2 的配置串口发送 ZL-IS2 ASCII 控制帧；控制器总线连接六个关节舵机。上述 40-pin 接线用于 M2 与 ZLink 控制板之间的 UART 通信。

默认串口配置位于项目根目录的 **config.yaml**：

- 后端：**zl_is2**
- 串口：**/dev/ttyS1**
- 波特率：**115200**

实际设备使用不同串口时，只修改 **serial.port**；控制器后端固定为 ZL-IS2。

## 关节映射

部分新购机械臂的总线舵机可能全部使用出厂默认 ID 000。首次使用前，按 ZL-IS2/ZLink 随附的官方说明逐个设置舵机 ID；多个舵机仍使用相同 ID 时，不要直接运行本 Demo。项目不会自动修改舵机 ID。

本项目要求 J1–J6 分别设置为唯一 ID 000–005，关节映射如下：

| 关节 | 舵机 ID |
|---|---:|
| J1 | 000 |
| J2 | 001 |
| J3 | 002 |
| J4 | 003 |
| J5 | 004 |
| J6 | 005 |

中心位置、方向、位置比例与软限位均在 **config.yaml** 中定义。更换机械臂或舵机后，应根据对应设备的数据重新配置这些值。

## 运动与电压参数

运动调度和低压阈值也读取 **config.yaml**：

- 并发运动轴数上限：**3**
- 重轴 ID：**1、2**
- 重轴最短动作时长：**1200 ms**
- 低压提示阈值：**7000 mV**
- 停机阈值：**6800 mV**

如需调整，请同时确认软件配置与实际硬件规格一致。
